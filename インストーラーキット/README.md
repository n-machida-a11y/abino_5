# インストーラーキット

3つの xlsm に最新 VBA を一括取り込むためのキット。

## フォルダ構成

```
インストーラーキット/
├── 現場用/        ← 【全社展開用】工事番号入力管理表.xlsm へ
├── 管理者用/      ← 【管理者入力用】工事番号管理表.xlsm へ
├── 経理用/        ← 【共有_経理用】請求書作成.xlsm へ
└── 手動コピペ用/  ← VBE上で全文コピペで適用したい人向け
```

## インストール手順（共通）

1. 対象 xlsm を開く
2. `Alt + F11` で VBE
3. プロジェクトで右クリック → 「ファイルのインポート」
4. 対応するキットフォルダの `VBAインストーラー.bas` をインポート
5. `Alt + F8` → `InstallAll` を実行
6. フォルダ選択で対象キットフォルダを選ぶ
7. 失敗 0 件を確認

## 注意

- ユーザーフォーム(.frm)は VBAインストーラーでは置き換わりません。
  フォーム本体を更新する場合は `手動コピペ用/` の対応する .txt を
  各フォームのコードに貼り付けてください。
- 標準モジュール(.bas)と ThisWorkbook はインストーラーで自動更新されます。
