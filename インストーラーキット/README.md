# 📦 インストーラーキット（2026/5月リリース版）

このフォルダには、お客様の3つの xlsm に最新VBAを一括反映するためのキットが入っています。

---

## 🗂️ フォルダ構成

```
インストーラーキット/
├── 現場用/        ← 【全社展開用】工事番号入力管理表.xlsm へ
├── 経理用/        ← 【共有_経理用】請求書作成.xlsm へ
└── 管理者用/      ← 【管理者用】工事番号管理.xlsm へ
```

各フォルダに「対象xlsm に入れる .bas / .frm / .cls 一式」と「VBAインストーラー.bas」が入っています。

---

## 🚀 インストール手順（共通）

### 事前準備
1. **対象xlsmのバックアップ** を必ず別フォルダに取る
2. Excelの設定で「VBAプロジェクトオブジェクトモデルへのアクセスを信頼」にチェックが入っているか確認
   - `ファイル → オプション → セキュリティセンター → セキュリティセンターの設定 → マクロの設定`

### 手順
1. 対象xlsmを開く
2. `Alt + F11` でVBAエディタを起動
3. プロジェクトウィンドウで **xlsm名 を右クリック → ファイルのインポート**
4. `VBAインストーラー.bas` を選択してインポート
5. xlsm画面に戻り、`Alt + F8` でマクロ一覧を開く
6. **`InstallAll`** を選択して実行
7. フォルダ選択ダイアログで、対象キットのフォルダ（例：「現場用」）を選ぶ
8. 確認ダイアログで「はい」
9. 完了メッセージに **失敗件数が 0** ならOK
10. **xlsmを上書き保存** して完了

## ⚙️ インストール後の設定（最重要）

### 現場用（全社展開用 xlsm）
- 「**入力フォーム**」シートの **A37セル** に部門コードを入力
  - 建築事業部 → `03`
  - 土木事業部 → `05`（仮）
  - 空欄なら "03" にフォールバック

### 管理者用 xlsm
- 部門ごとに別物として配布する場合は、VBE で `管理者設定用コード` モジュールを開いて：
  ```vba
  Public Const MY_DEPT_CODE As String = "03"
  ```
  の値を部門別に書き換える（建築=03、土木=05）
- 全部署統合版なら "03" のまま（建築のみ対象）

### 経理用 xlsm
- 部門コード不要
- 「依頼履歴」シートの **G1セル** にマスタパス（変更ない場合は再設定不要）
- 「依頼検索」シートの **C1セル** に請求書の保存先パス

## ⚠️ トラブルシュート

### 「VBEへのアクセスが許可されていません」と出る
→ Excelの「VBAプロジェクトオブジェクトモデルへのアクセスを信頼」にチェックを入れて再実行

### 「× 削除失敗」と出る
→ そのモジュールが現在実行中の可能性。Excelを一度閉じて開き直し、再実行

### 「× インポート失敗」と出る
→ ファイル名にエラーがないか、文字化けしていないか確認。キットフォルダを丸ごとコピーし直す

### インストール後に文字化け
→ キットファイルが cp932(Shift-JIS) で配布されていること、UTF-8 で再保存されていないことを確認
