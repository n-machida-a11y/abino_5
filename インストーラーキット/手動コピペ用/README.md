# 📋 VBA手動コピペ用ファイル

インストーラーを使わず、VBE上で全文コピペして適用するためのコード一式です。

|---|---|---|---|

## 🔧 貼り付け手順（共通）

### Step 1: 対象xlsmを開く
バックアップを取ってから開いてください。

### Step 2: VBEを起動
`Alt + F11`

### Step 3: 対象モジュールを開く
- **フォームの場合**: 左ペインで対象フォームを **右クリック → 「コードの表示」**
- **ThisWorkbook**: 左ペインで `ThisWorkbook` を**ダブルクリック**
- **標準モジュール**: 左ペインで対象モジュールを**ダブルクリック**

### Step 4: 既存コードを全削除
コード画面で：
1. `Ctrl + A`（全選択）
2. `Delete`（削除）

### Step 5: 新しいコードを貼り付け
1. このフォルダの該当 `.txt` ファイルをメモ帳などで開く
2. `Ctrl + A` で全選択コピー
3. VBE のコード画面に `Ctrl + V` で貼り付け

### Step 6: 保存
xlsmに戻って `Ctrl + S`（マクロ有効ブックで保存）

### Step 7: コンパイル確認
VBE のメニュー → **デバッグ → VBAProjectのコンパイル** → エラーが出なければOK

## ⚠️ 注意点

- `.txt` ファイルは **UTF-8 BOM付き** で保存されています。メモ帳・VS Codeなどで開いてOK
- コピペ時は `Option Explicit` から最後の `End Sub` / `End Function` まで含めてください
- 貼り付け先のモジュールは **必ず先に全削除** してから貼り付け（既存コードと混ざらないように）

---

## 🆘 エラー時

「プロシージャのもとでは無効」「型が一致しません」等のエラーが出た場合は、コピペ範囲が不完全な可能性があります。再度全文コピペし直してください。

それでも解決しない場合は、エラーの完全な文言と発生行を連絡ください。
