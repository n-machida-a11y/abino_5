# 📝 【共有_経理用】請求書作成.xlsm セッティングガイド

初回 or 環境変更時にご確認いただく設定項目をまとめました。
**所要時間: 5分程度**

---

## 📌 設定するのは2箇所だけ

| # | 設定箇所 | 何を設定するか |
|---|---|---|
| ① | **依頼履歴シート G1** | マスタファイルのパス（読み取り元） |
| ② | **依頼検索シート C1** | 請求書の保存先（書き出し先） |

どちらも**シート上のセルに直接入力**するだけ。VBAや設定画面は触りません。

---

## ① マスタファイルのパス（依頼履歴シート G1）

### 目的
現場担当者・管理者が入力している **`工事番号管理表.xlsm`（マスタ）** の場所を経理Excelに教えます。これで「検索実行」時に最新の依頼履歴が取得できます。

### 設定手順

1. `【共有_経理用】請求書作成.xlsm` を開く
2. **「依頼履歴」シート**タブを選択
3. **G1 セル** を選択
4. マスタファイルのフルパスを入力

### 入力例

```
Z:\全社共有\建築事業部\30_事務\工事番号管理\工事番号管理表.xlsm
```

### 📌 ポイント
- **ファイル名(.xlsm)まで含める**（フォルダだけじゃない）
- パスのコピペは、エクスプローラーのアドレスバーからコピーすると確実
- ダブルクォート `"..."` で囲んでも自動除去されるので気にしなくてOK

---

## ② 請求書の保存先（依頼検索シート C1）

### 目的
保存ボタンを押した時に **どこに請求書xlsxを保存するか** を指定します。

### 保存されるパス構造

```
C1で指定したフォルダ
  └ YYYY年M月請求書    ← 自動作成
       └ 1_請求書_㈱○○_△△工事_03-2503-001.xlsx  ← 請求書ファイル
```

月別フォルダは自動で作られるので、**C1には「共通の親フォルダ」だけ**指定すればOK。

### 設定手順

1. `【共有_経理用】請求書作成.xlsm` を開く
2. **「依頼検索」シート**タブを選択
3. **C1 セル** を選択
4. 保存先のフォルダパスを入力

### 入力例

| ケース | C1の入力値 |
|---|---|
| 個人のPCに保存 | `C:\請求書保存` |
| 共有ドライブに保存 | `Z:\全社共有\請求書保存場所` |
| 社内ネットワーク共有 | `\\サーバー名\共有\請求書` |
| 未入力（空欄） | 自動で Downloads フォルダに保存 |

### 📌 ポイント
- 末尾の `\` は **あってもなくてもOK**（自動で処理）
- ダブルクォートで囲んでもOK（自動除去）
- **空欄でもエラーにならない**（Downloadsにフォールバック）

---

## 🔍 設定確認

設定したら、以下の順でテストしてください：

### ①マスタへのアクセス確認
1. 「依頼検索」シートの A2 に既存の依頼NOを入力（例: `301` など）
2. **「検索実行」** ボタンを押下
3. データが取得・表示されればOK
4. エラーが出た場合 → G1 のパスを見直し

### ②保存先確認
1. 「請求書作成」メニューから適当な種類（請求書など）を1つ作成
2. 作成された「No_xx_請求書」シートに移動
3. **「保存」** ボタンを押下
4. 完了メッセージに表示されるパスを確認
5. そのパスにxlsxファイルができていればOK

---

## 🆘 困ったときは

### 🔴「マスタファイルにアクセスできません」と出る
- **G1の値** を確認
- エクスプローラーでそのパスを開けるか確認
- Zドライブが接続されているか（切断されていると取れない）

### 🔴「保存フォルダが作成できませんでした」と出る
- **C1の値** を確認
- 指定したフォルダの**親フォルダが実在**するか確認
  - 例: C1=`Z:\共有\請求書` の場合、`Z:\共有` が存在している必要あり
- アクセス権限があるか確認

### 🔴「ファイル名が取得できません」と出る
- これは「請求書作成」マクロ未実行で保存ボタンを押した場合
- **先に「請求書作成」メニュー** を実行してから保存を実行
