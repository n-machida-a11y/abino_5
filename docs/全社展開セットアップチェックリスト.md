# 全社展開セットアップチェックリスト

新部門（環境=02 / 営繕=04 / 構内=06 / 企画開発=11 / 九州=13）へ
工事番号管理システムを展開する際の必須チェックリスト。
**1つでも漏れると動かない／誤動作する**項目に ★ を付けている。

---

## 1. 共有マスタファイル（工事番号管理表.xlsm）— 全部門共通で1つ

| ✓ | 項目 | 漏れた場合の症状 |
|---|---|---|
| ★ | 「担当者マスタ」シートに全部門の担当者を登録（A=氏名 / B=部門番号2桁） | 担当者ドロップダウンに名前が出ない |
| ★ | 複数部門担当者（企画開発）は**部門ごとに複数行**で登録 | 渡した部門ファイルに名前が出ない |
| ★ | 「依頼書セル設定」シートが存在し、項目が入力済み | 依頼書作成時に警告→作成失敗 |
| | 「管理マスタ」シートの設定値（G3/G5等の対象シート名）が正しい | 登録・再登録フォームが対象シートを見つけられない |
| | 「その他マスタ」シート（請求先リスト）が存在 | 請求書提出先の候補が出ない |
| | 依頼履歴シートのA3以降が空（番号リセット済み）であること | 依頼書No.が途中の番号から始まる |

## 5. 運用上の注意（複数部門でマスタを共有するため）

- **依頼書No.は全部門共通の通し番号**になる（部門ごとに1からではない）
- 登録・依頼書作成時に「他のユーザーが使用中」と出たら、**少し待って再実行**（マスタは同時に1人しか書き込めない）
- 管理者の「マスタへ反映」は**部門間で時間をずらして**実行するのが安全
- 「管理マスタ」「その他マスタ」「依頼書セル設定」は全部門共通のため、
  **複数部門の管理者が同時期に編集すると後から反映した方で上書きされる**。
  これらのシートを変更する際は変更担当を1人に決めること

## 6. 動作確認（部門ごとに最低1回）

1. 入力用xlsmを開く → 部門コード警告が**出ない**こと（A37設定済みの確認）
2. 「更新」→ 自部門の工事だけ表示されること
3. 新規登録 → 工事番号が「自部門コード-…」で採番されること
4. 依頼書作成 → エラーなく完了し、PDF出力できること
5. 依頼履歴に行が追記され、明細（Z列）が保存されていること
6. 経理側で依頼NO検索 → ヒットし、部署名が正しく印字されること
