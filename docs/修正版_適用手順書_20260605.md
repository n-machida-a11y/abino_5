# 修正版 適用手順書（2026/06/05）

お客様アップロードの 2 ファイル（管理者入力用 / 入力用・建築）を、最新 VBA に更新する手順。

> 適用は **Excel 上で実施**します（VBA は Excel の VBProject 経由でしか確実に再コンパイルされないため）。

> ユーザーフォーム(.frm)は **手動コピペ用 txt** をコード窓に貼り付けます。

## 1.【入力用・建築】工事番号入力管理表 への適用

### 1-1. InstallAll で .bas / ThisWorkbook を自動更新
1. 対象 xlsm を開く → `Alt+F11`（VBE）
2. `VBAインストーラー.bas`（`インストーラーキット/現場用/`）をインポート
3. `Alt+F8` → **InstallAll** 実行 → `インストーラーキット/現場用/` フォルダを選択
4. 「失敗 0 件」を確認
   - 更新される .bas: `PDF作成 / 呼び出し / 更新 / 削除フォームを開く / 登録フォームを開く / 設定用コード` と `ThisWorkbook`

### 1-2. フォームは手動コピペ（.frm はインストーラーで置換されない）
各フォームを開き `F7` でコード窓 → **全選択して削除 → 下記 txt を全文貼り付け**：

| フォーム | 貼り付ける txt | 必須度 |
|---|---|---|
| 依頼書作成 | `②【全社展開用】依頼書作成.txt` | ★必須（バグ修正含む） |
| 再登録 | `⑫【全社展開用】再登録.txt` | ★必須（担当者フィルタ） |
| 削除フォーム | `⑬【全社展開用】削除フォーム.txt` | ★必須（担当者フィルタ） |
| 登録ボタン | `①【全社展開用】登録ボタン.txt` | 任意（軽微） |
| 工事名称選択 | `⑪【全社展開用】工事名称選択.txt` | 任意（コメントのみ） |

### 1-3. 設定値の確認（★最重要）
| 場所 | 設定 |
|---|---|
| 「入力フォーム」シート **A36** | 共有マスタのフルパス（設定済みを確認） |
| 「入力フォーム」シート **A37** | 自部門コード（建築=`03`）。**空欄だと起動時に警告**（建築扱いで動作はする） |
| VBE 設定用コード `IS_TEST_MODE` | **`False`**（⑨/現場用キットは False 済み） |

## 2.【管理者入力用】工事番号管理表 への適用

> 必要な変更はすべて .bas / ThisWorkbook（フォームなし）なので InstallAll で完結します。

### 2-1. InstallAll
1. 対象 xlsm を開く → `Alt+F11`
2. `VBAインストーラー.bas`（`インストーラーキット/管理者用/`）をインポート
3. `Alt+F8` → **InstallAll** → `インストーラーキット/管理者用/` を選択 → 失敗 0 件
   - 更新: `管理者操作 / 管理者設定用コード / ThisWorkbook`
   - 反映される機能: **起動時の保護自動解除**（ThisWorkbook）・**反映データの文字色を黒へリセット**（管理者操作）

### 2-2. 設定値の確認（★最重要）
| 場所 | 設定 |
|---|---|
| 「操作」シート **B1** | 自部門コード（建築=`03`） |
| 「操作」シート **A1** | 通常 **空欄**（テスト時のみテスト用マスタパス） |
| VBE 管理者設定用コード `IS_TEST_MODE` | **`False`**（管理者用キット・⑩txt は False 済み） |

## 3. 適用後の動作確認（Excel 上で実施してください）

- [ ] VBE で「デバッグ → VBAProject のコンパイル」が**エラーなく通る**
- [ ]【入力用】新規登録 → 工事番号が `03-26xxxxx`（部門+年度2桁+5桁通番）で発番される
- [ ]【入力用】依頼書作成 → 明細1行目に「上記工事」が初期表示／作成後に当該行がグレーになる
- [ ]【入力用】再登録・削除フォームで担当者ドロップダウンに自部門の担当者だけ出る
- [ ]【管理者】最新取得 → マスタへ反映 → ローカル一覧が**黒字**で表示される
- [ ]【管理者】保護がかかっておらず手編集できる

> 共有マスタ（工事番号管理表）側に「担当者マスタ」シート（A=氏名/B=部門番号2桁）と
> 「依頼書セル設定」シートが整備されていることが前提です（`docs/全社展開セットアップチェックリスト.md` 参照）。
