## 📋 今回のアップデート内容

1. **依頼書（請求書提出依頼書）のレイアウト改善**
2. **PDF作成機能の改善**
3. **「依頼書セル設定」シートの新規導入**
4. **管理者様専用Excelの新規提供**

### ① 【全社展開用】工事番号入力管理表.xlsm
- 依頼書フォームが新レイアウトに対応
- 消費税の表記変更：「（ 内 消費税 10％ 1,250,000円 ）」→「（ 内消費税　　￥1,250,000 ）」
- 提出依頼者の所属部署（「建築事業部」など）が自動で入ります
- PDF保存の動作が安定化（ファイル名が正しくつきます）

### ② 【共有_経理用】請求書作成.xlsm
- マスタ保存が失敗した時に分かりやすいメッセージが出ます
- 「マスタへ再同期」ボタンを追加（失敗時のリトライ用）
- 保存失敗時にご入力内容が消えにくくなりました

### ③ 「依頼書セル設定」シート（新規・マスタに追加）
これまで依頼書のレイアウト情報はVBAコード内に埋め込まれていたため、「宛名の位置を変えたい」といった要望のたびにコード修正が必要でした。
今回から**この情報をシート上に一元管理**する形に変更し、今後のメンテナンスがしやすくなります。

通常操作では触らないシートで、レイアウト変更時の設定用とお考えください。

### ④ 【管理者用】工事番号管理.xlsm（新規）
これまで管理者様がマスタファイルを直接開いて編集されていた際、現場・経理のファイル書き込みとタイミングがかぶって失敗することがありました。これを解消する**管理者様専用ファイル**です。

使い方：
1. ファイルを開く
2. 「マスタから最新取得」ボタンで最新データ読み込み
3. シート上で直接編集
4. 「マスタへ反映」ボタンで書き戻し

※ 管理者様が編集中に他の方が新しい工事を登録しても、その内容は失われずに保持されます。
