# 経理用VBA（【共有_経理用】請求書作成.xlsm）

## 📂 ファイル構成

| ファイル | 役割 | 主要マクロ |
|---|---|---|
| `Keiri_設定用コード.bas` | 設定値の一元管理（VB_Name="Config"） | GetMasterPath |
| `Keiri_シート更新.bas` | マスタとの双方向同期 | マクロ_検索実行 / マクロ_上書き保存 / マクロ_新規作成 |
| `Keiri_請求書作成.bas` | 請求書テンプレ複製＆データ転記 | AssignAccountingInvoiceNo |
| `保存.bas` | 請求書を xlsx として保存 | 保存_印刷作業 |

## 🔧 デプロイ前の必須設定

| 場所 | 設定値 |
|---|---|
| Config モジュール | `IS_TEST_MODE = False` |
| 依頼履歴!G1 | マスタファイルのフルパス |
| 依頼検索!C1 | 請求書保存先のベースフォルダ |

## 🌐 データの流れ

```
[マスタ 工事番号管理表.xlsm] ←→ [経理用ブック]
   依頼履歴シート               依頼検索シート
                              ↓
                              請求書テンプレ → No_xx_請求書 → xlsx
```
