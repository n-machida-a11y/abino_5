# abino_5 - 工事番号管理システム VBA

阿比野建設様の工事番号管理システム VBAコード一式（最新版）。

---

## 📁 ディレクトリ構成

```
abino_5/
├── kouban_zensya/   現場担当者用（【全社展開用】工事番号入力管理表.xlsm 用）
├── keiri/           経理担当者用（【共有_経理用】請求書作成.xlsm 用）
├── kanri/           管理者用（【管理者用】工事番号管理.xlsm 用）
└── docs/            お客様向けドキュメント
```

---

## 🆕 主な変更点（2026/5月リリース）

### 1. 工事番号採番ルール変更（2026/6/1〜建築事業部）
- 旧: `03-YYZZ-NNN` (年度2桁+担当者番号2桁+3桁通し番号)
- 新: `03-YY-NNNNNN` (年度2桁+6桁通し番号)
- 担当者番号は工事番号から削除（行データには引き続き記録）

### 2. 部門コードの可変化（全社展開準備）
- `入力フォーム!A37` セルに自部門コードを設定可能
- 採番プレフィックス・AutoFilter両方で使用
- 建築事業部: "03" / 土木事業部: "05"（仮）等
- 既定（A37空欄）は "03"

### 3. 工事番号一覧の部門別フィルタ
- 「更新」マクロ実行時、自部門コードで AutoFilter を自動適用
- D列(工事番号一覧)または E列(依頼履歴) の前方一致

### 4. その他の改善
- PDF作成のファイル名取得を Named Range 化（レイアウト変更耐性）
- マスタ同期失敗時の救済（マクロ_マスタへ再同期 ボタン）
- 依頼検索シート C1 セルで保存先パスを設定可能
- 各種エラーメッセージの詳細化

## 🔧 各フォルダの役割

### kouban_zensya/
現場担当者が日々使う Excel のVBA。新規登録・依頼書作成・PDF出力・各種マスタ更新。

### keiri/
経理担当者が請求書を作成・保存する Excel のVBA。依頼検索・経理番号採番・請求書出力。

### kanri/
管理者が複数部署のデータを統合管理する Excel のVBA。
「マスタから最新取得 → 直接編集 → マスタへ反映」の差分マージ方式。

### docs/
お客様への案内文書（メール文面・セットアップ手順・パス設定ガイドなど）。
